# Jl-Media-Manager
Turns a Wallpaper Engine workshop (`steamapps\workshop\content\431960`) into a library sized for the **Jungle Leopard 9.16" bar** (`D215-NOR-FL7707N-9.16inch-hor`, 1920×462), and builds playlist folders that **Jungle Leopard Display** plays with its own *Media → Slideshow* feature.
